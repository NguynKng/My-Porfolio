## 8. Design Direction for ChatGPT / AI Website Generator

Create a modern developer portfolio suitable for a Fresher/Junior
Full-stack Developer.

### Visual direction

-   Clean, modern, minimal, and professional.
-   Strong typography and generous whitespace.
-   Avoid an overly futuristic "AI developer" aesthetic.
-   Avoid excessive neon gradients, glassmorphism, glowing borders,
    particles, or animated code rain.
-   The portfolio should feel like a real software engineer's
    professional site, not a template-heavy landing page.
-   Support responsive desktop, tablet, and mobile layouts.
-   Dark mode is optional; if included, both light and dark themes
    should remain highly readable.
-   Use subtle transitions and micro-interactions rather than heavy
    animation.

### Project presentation

Projects are the most important section.

For each featured project: - Show project title and concise one-sentence
description. - Show role and period. - Show 3--5 key contributions. -
Show a compact technology list. - Allow screenshots to be added later. -
Provide buttons only when a real URL exists. - Servio should receive the
strongest visual emphasis. - Do not invent user counts, revenue,
performance improvements, download counts, production traffic, or
business metrics.

### Content style

-   Keep copy concise.
-   Prefer concrete verbs: Built, Developed, Implemented, Integrated,
    Contributed.
-   Do not describe the candidate as an expert, senior engineer,
    architect, DevOps engineer, or AI engineer.
-   Do not claim ownership of CI/CD pipelines or infrastructure that is
    not explicitly documented.
-   Avoid fake percentage improvements and fake performance metrics.
-   Do not inflate project complexity.
-   Keep the positioning credible for Fresher/Junior roles.
